# E-Hinga Smart Farms — Farmer App

Pixel-style PWA. **No backend required.**

## Run on iPhone

1. `cd frontend && npm install && npm run dev`
2. Open the LAN URL on your iPhone (same Wi‑Fi)
3. Safari → **Share** → **Add to Home Screen**
4. Launch **E-Hinga** — splash + standalone app chrome

## Product story (judges)

| | |
|---|---|
| **What** | Crop disease spreads before farmers get expert help |
| **Solves** | Instant diagnosis + clear treatment + local officer |
| **How** | Capture → Understand (Gemini) → Act |
| **When** | Yellow leaves, spots, sick livestock, or rain coming |

## Demo path

**Demo Mode (Judges)** → diagnosis → Veo field video → officer escalation
